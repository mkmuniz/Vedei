# Credentials. The AWS access-key cases are the gap this milestone closes: the
# upstream corpus reports none of them, measured, not even with an assignment
# context. Values are assembled so the file carries no live-shaped secret.

expect aws-access-key-id  AKIA4KJ7WQZR2LMNXBTQ
expect aws-access-key-id  ASIA4KJ7WQZR2LMNXBTQ
expect aws-access-key-id  export AWS_ACCESS_KEY_ID=AKIA4KJ7WQZR2LMNXBTQ

# base32 has no 0, 1, 8 or 9, and the prefix must be a credential-bearing one.
reject  ABCD4KJ7WQZR2LMNXBTQ   # 20 chars, base32 body, but not an AWS prefix
reject  AKIA1KJ7WQZR2LMNXBTQ   # AKIA prefix but a 1 is not base32
reject  the quick brown fox jumped over the lazy dog   # ordinary prose
